# Code of Conduct

Be respectful, stay on topic and assume good faith. Harassment and personal
attacks are not accepted in issues, pull requests or any other project space.

The maintainer, [@furstma](https://github.com/furstma), may edit or remove
comments, lock threads and block accounts that break these rules.

To report a problem, mention the maintainer in the thread. If you would rather
not raise it in public, use GitHub's
[report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
function on the comment or profile in question; that report goes to GitHub,
not to the maintainer.
