# Security policy

This library signs messages for the tax administration and decides whether a
reply can be trusted. Please report anything that weakens either.

## Reporting a vulnerability

Report it privately through GitHub: open the repository's **Security** tab and
choose **Report a vulnerability**
(<https://github.com/furstma/eet-client/security/advisories/new>).
Please do not open a public issue.

Do not attach real certificates, private keys or passwords. The public
Playground certificates are enough to show a problem.

## Supported versions

Fixes go into the latest release only.
